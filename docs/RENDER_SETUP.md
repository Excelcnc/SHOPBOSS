# Put CNC Quote online with Render

Render hosts the whole app from this GitHub repository. Once it is set up, every change pushed to the
branch goes live by itself. No servers to look after.

What Render creates (from `render.yaml`):

| Piece | Render plan | What it does |
|---|---|---|
| `cnc-quote` web service (Docker) | Standard (2 GB) | Website, API, 3D/drawing analysis worker, mailbox checker |
| 10 GB disk on that service | — | Uploaded drawings, models and quote PDFs |
| `cnc-quote-db` PostgreSQL | Basic 1 GB | All data |
| `cnc-quote-redis` Key Value | Starter | Analysis job queue |

Check current prices on render.com/pricing before you start. At the time of writing this setup was
roughly $55–70 a month; it does not use any free plans (Render's free database is deleted after a month).

Time needed: about 30 minutes, plus 10–15 minutes for the first build.

---

## 1. Create the Render account

1. Go to **render.com** and choose **Get Started**.
2. Choose **GitHub** and sign in with the GitHub account that owns `Excelcnc/SHOPBOSS`.
3. When GitHub asks which repositories Render may see, choose **Only select repositories →
   SHOPBOSS**.
4. Add a payment card under **Billing** (paid plans are needed for the database and disk).

## 2. Set up outgoing email (for sign-up codes and invitations)

New users get a 6-digit code by email to prove their address. The app sends it through an email
service. Any SMTP service works; **Resend** is simple and has a free tier for low volumes:

1. Sign up at **resend.com**.
2. **Domains → Add domain** → `excel-cnc.com` (or a subdomain such as `mail.excel-cnc.com`).
3. Resend shows 3–4 DNS records. Add them where your domain's DNS is managed (GoDaddy, Network
   Solutions, Cloudflare, Microsoft 365 admin center…). Wait until Resend shows **Verified**.
4. **API Keys → Create API key** (permission: Sending access). Copy it; it's shown once.

You'll use these values in step 3:

| Setting | Value |
|---|---|
| `SMTP_HOST` | `smtp.resend.com` |
| `SMTP_USER` | `resend` |
| `SMTP_PASSWORD` | the API key (secret) |
| `SMTP_FROM` | `CNC Quote <noreply@excel-cnc.com>` |

Without email the app still works, but new accounts aren't verified and nobody can reset a forgotten
password. Don't open sign-up to other shops until email is set up.

## 3. Create the app from the Blueprint

1. In Render: **New + → Blueprint**.
2. Pick the **SHOPBOSS** repository and the branch (`m365-signin` until it's merged, then `main`).
3. Render reads `render.yaml` and lists the three pieces above. It then asks for the settings marked
   *sync: false*. Fill in:

   | Setting | What to enter |
   |---|---|
   | `APP_URL` | leave empty for now (filled in step 4) |
   | `SMTP_HOST`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` | from step 2 |
   | `GRAPH_TENANT_ID` | `782edd6a-46a8-416f-942f-d890b567234e` |
   | `GRAPH_CLIENT_ID` | `02a1a3b2-f8ea-4f71-889e-89937d38902b` (the "CNC Quote mailbox" app) |
   | `GRAPH_CLIENT_SECRET` | the mailbox app's client secret **Value** (Entra → App registrations → CNC Quote mailbox → Certificates & secrets). Secret: paste it only here. |
   | `GRAPH_SHOP_DOMAINS` | `excel-cnc.com` |
   | `ENTRA_CLIENT_ID`, `ENTRA_TENANT_ID` | leave empty (see step 7) |
   | `ANTHROPIC_API_KEY` | optional: turns on AI reading of emails and scanned drawings |

   `SECRET_KEY` and `GRAPH_CLIENT_STATE` are generated by Render automatically. Never change
   `SECRET_KEY` later: it signs everyone's sessions and encrypts saved mailbox passwords.
4. Choose **Apply**. The first build takes 10–15 minutes (the 3D engine is large).

## 4. Tell the app its own address

1. Open the **cnc-quote** service. At the top is its address, like
   `https://cnc-quote.onrender.com` (yours may have extra letters).
2. **Environment → APP_URL** → paste that address → **Save changes**. The app restarts in about a
   minute. This turns on instant email delivery from Microsoft 365 and puts the right link in emails.

## 5. Create your account and connect purchasing@

1. Open the address. Choose **Create an account**.
2. Enter your **@excel-cnc.com** email, your name, **Excel CNC** as the shop name, and a password.
3. Enter the 6-digit code from your inbox. You're in, as the shop's admin.
4. **Shop settings → Email accounts → Connect a mailbox → Microsoft 365 / Outlook**:
   `purchasing@excel-cnc.com`, folder `RFQ` → **Connect**. The test should say *Connected… N messages*.
   (This works only for accounts proven at `excel-cnc.com`: that's what `GRAPH_SHOP_DOMAINS` does, so
   other shops can never connect your mailboxes.)
5. **Shop settings → Team** → invite your estimators by email.

## 6. Your own web address (optional)

To use `quote.excel-cnc.com` instead of `….onrender.com`:

1. **cnc-quote → Settings → Custom Domains → Add** → `quote.excel-cnc.com`.
2. Render shows a **CNAME** record. Add it at your DNS provider. Render issues the https certificate
   itself.
3. Change `APP_URL` to `https://quote.excel-cnc.com`.

## 7. "Sign in with Microsoft" (optional)

Email accounts work for everyone, including Microsoft 365 users, so this is optional. To add the
button for Excel CNC staff:

1. Entra → App registrations → **CNC Quote** (sign-in app, `195f4887-…`) → **Authentication** →
   under **Single-page application** add the app's address (e.g. `https://cnc-quote.onrender.com`).
2. In Render set `ENTRA_CLIENT_ID=195f4887-cb07-462a-bf97-ad0089629f4d` and
   `ENTRA_TENANT_ID=782edd6a-46a8-416f-942f-d890b567234e`.

With that tenant ID, only Excel CNC accounts can use the Microsoft button; other shops use email
sign-up. Opening the Microsoft button to every company needs the sign-in app switched to
"Accounts in any organizational directory" and `ENTRA_TENANT_ID=organizations`.

## 8. Opening sign-up to other shops

Sign-up is open by default (`SIGNUP_OPEN=true`): anyone can create an account and gets their own,
separate shop with default rates. To keep it invite-only while testing, set `SIGNUP_OPEN=false`; then
only people invited from **Team** can create accounts.

Before inviting other shops, read docs/STATUS.md, especially *export-controlled (ITAR/EAR) drawings*:
an ordinary cloud host is not suitable for ITAR technical data.

---

## Everyday

- **Updates:** pushing to the branch redeploys automatically; database changes are applied on start.
- **Logs:** cnc-quote → **Logs**. Mailbox problems also show on **Shop settings → Email accounts**.
- **Backups:** cnc-quote-db → **Recovery** (Render keeps daily backups on paid database plans).
- **Mailbox check from the server:** cnc-quote → **Shell** → `python -m app.check_m365 purchasing@excel-cnc.com`.
